5. Limitations / what went wrong

Legacy v1 is not a valid within-block experiment.

  • 0 target-block probes; all probes landed after the first target slot.
  • Fee tiers collapsed into on-chain ties (e.g., 5001/5002/5003 lamports).
  • Timestamps were synthesized at 80 ms intervals; on-chain memo times differ.
  • Contention/saturation JSON were dry-run simulator output presented as empirical.
  • The roster contained an invalid validator identity.
  • The old report claimed p < 0.001 and conclusive scheduling; this analysis does not reproduce that.

6. Machine-generated warnings

  • This is the legacy v1 dataset. It has no target-block probes, uses the legacy fee-tier design (many on-chain fee ties), and its original report applied cross-block correlations. Treat it as diagnostic only.
  • No probe landed in any target block. Same-block target-block inference is therefore impossible for this campaign.
